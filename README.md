# \# JDEA Interim Project – E-commerce Data Analytics

# 

# \## Project Overview

# 

# This repository contains datasets prepared for the JDEA Interim Project. The data supports exploratory data analysis, data preparation, and analytical work related to e-commerce sales and product profitability.

# 

# \## Dataset Description

# 

# | File | Description |

# |---|---|

# | `sales1.csv` | Sales data for analysing sales activity and order trends. |

# | `product\_profitability.csv` | Product profitability data for evaluating product-level financial performance. |

# | `pca.csv` | Data associated with Principal Component Analysis (PCA) for dimensionality reduction or further analysis. |

# | `combine.csv` | Combined dataset intended to support broader analysis across the available data. |

# 

# \## Project Objectives

# 

# \- Explore and understand e-commerce datasets.

# \- Prepare and transform data for analysis.

# \- Analyse sales performance and product profitability.

# \- Apply appropriate data analytics techniques to derive insights.

# \- Support the development of the JDEA Interim Project deliverables.
